# Flip Clock for macOS

Open Terminal in this folder and run:

```sh
sh "Install macOS.command"
```

Open **Flip Clock.app** from your user Applications folder (`~/Applications`). Chrome, Edge, Brave, or Chromium opens an app window; otherwise the clock opens in your default browser. No administrator access is needed. This is a local browser launcher, not a signed/notarized App Store app.

Press **S** for themes, wallpapers, custom images, adaptive glass, and sound. **F** toggles fullscreen. The toolbar includes a countdown timer. The Windows screensaver is not included.

To uninstall, move `~/Applications/Flip Clock.app` to Trash. Re-run the installer to update. Script syntax is checked; native macOS launching still needs verification.
